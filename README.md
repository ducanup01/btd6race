# 🏁 BTD6 Race Event Tracker

A simple tool for tracking changes in the **Bloons TD 6 Race Event** leaderboard.

🔗 **Live App**: [btd6race.streamlit.app](https://btd6race.streamlit.app)

## 📌 Overview

This Streamlit app captures snapshots of the BTD6 Race Event API at regular intervals and compares each snapshot to the original state. This allows users to observe how the leaderboard changes over time.

Also includes a history archive of all races ever!

## 🛠️ Notes

- Updates once every 15-20 minutes. Might take longer at midnight EST timezone.
- Rely solely on NK's open API.
